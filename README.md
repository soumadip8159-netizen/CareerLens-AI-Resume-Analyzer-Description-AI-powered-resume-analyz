CareerLens AI – Smart Resume Analyzer

An AI-powered resume analysis platform that helps students improve their resumes and prepare for job opportunities.

🚀 About the Project

CareerLens AI is a Python-based resume analyzer designed to help students and job seekers understand how well their resumes match a particular job description.

It analyzes resume content, identifies relevant skills, highlights missing skills and provides suggestions for improvement.

✨ Key Features

- 📄 Upload PDF, DOCX and TXT resumes
- 🎯 Resume readiness scoring
- 🔍 Job description matching
- 🧠 Skills gap identification
- 📊 Resume analysis and feedback
- 💡 Resume improvement suggestions
- 🤖 Optional Google Gemini AI-powered feedback
- 🎤 Interview preparation topics

🛠️ Technology Stack

- Python
- Streamlit
- Google Gemini API (optional)
- PyPDF
- Python-docx

⚙️ Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

🔑 Gemini API Configuration

Gemini AI features are optional.

Create a ".env" file and add:

GEMINI_API_KEY=your_api_key

Never upload your API key or ".env" file to GitHub.
